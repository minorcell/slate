# 界面规范

Slate 只做桌面。应用留在这一层；设置、应用信息、卸载都打开系统自己的页面，桌面不再做二级页。

画面背后是一张按窗口像素画的夜色山丘。左上是时间，下面是当前应用的名字。应用排成一行，贴在屏幕下方的磨砂底板上。

## 色板

令牌在 `app/src/main/res/values/colors.xml`，代码里不要写字面色值。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `background` | `#000000` | 全屏底色 |
| `tile_background` | `#0B0B0D` | 卡片底 |
| `shelf_plate` | 白色 8% | 底部应用行的底板 |
| `tile_glow` / `tile_stroke` | 白色 11% / 8% | 卡片微光与 1dp 内描边 |
| `icon_stroke` | `#E8E4DD` | 线稿图标（偏暖的纸白） |
| `text_primary` | 白色 94% | 标题、应用名 |
| `text_secondary` | 白色 46% | 日期、说明 |
| `text_eyebrow` | 白色 32% | 次要小字 |
| `focus_stroke` | 白色 92% | 焦点环 |
| `move_stroke` | `#FFB74D` | 移动模式描边（唯一的彩色） |

## 桌面结构

背景由 `wallpaper/Backdrop` 画出来，不打包大图。同时烤一张 320 像素宽的磨砂图。底板（`ui/home/FrostPlate`）只取自己身后的那一块，再压暗、描一圈亮边。这块电视是 Android 9，不做每帧实时模糊。

字体是 Inter 可变字体（`assets/fonts/`，OFL）。时钟用 Display 光学尺寸，行标题用 Text。Android 8.0 以下没有变体轴，退回系统无衬线。

左上是时间，下面写当前焦点的应用名。名字不写在卡片上。右上角是设置。设置获得焦点后按确定，打开电视自己的设置，和应用列表里的「系统设置」是同一个入口：`com.android.tv.settings` 的启动页。不要用 `android.settings.mtk.SETTINGS` 或 `com.android.settings.Settings`，这台电视上那两个会打开安卓原生设置。

下面只有一行 **应用**：全部可启动应用，不做隐藏，也不做常用。长按可以移动、查看信息、卸载。左右重排后记在 `prefs.order`。

## 卡片

- 尺寸按窗口真实像素的比例计算（`ui/shell/ScreenMetrics.kt`），不用固定 dp。
- 宽为屏宽的 17%，高按 16:9。
- 居中放启动图标，不用 `android:banner` 铺满。不少应用的 banner 只是图标加一行字，铺进 16:9 会变成放大的图标。
- 表面用 `@drawable/tile_bg`，再用圆角裁切。
- 卡片和焦点环之间留一条缝，环画在卡片外侧。

## 焦点

- 焦点环白色，移动模式换成 `move_stroke`。卡片放大 1.07 倍，动画 220ms。
- 左右在行内移动，不循环。这一行再往上是设置按钮。从设置往下回到原来的卡片。
- 移动模式时，标题上方显示「方向键移动 · OK 完成」。确定或返回都结束移动并保存。

## 离开桌面

- 确定：打开这个应用。
- 长按里的应用信息、卸载：打开系统对应页面。
- 设置：打开系统设置。
- 这些页面回来之后，桌面还在，焦点还在原来的卡片上。

## 文案

- 只写中文，不再维护英文资源。
- 短句，一句说清一个动作。按钮用动词，说明用陈述句。
