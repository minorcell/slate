# 界面规范

Slate 的界面只有一种语气：黑底、暗色卡片、纸白线稿。所有新界面都按这份规范画，不再临时挑颜色。

## 色板

令牌在 `app/src/main/res/values/colors.xml`，代码里不要写字面色值。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `background` | `#000000` | 全屏底色 |
| `tile_background` | `#0B0B0D` | 卡片表面 |
| `tile_glow` / `tile_stroke` | 白色 11% / 8% | 卡片微光与 1dp 内描边 |
| `icon_stroke` | `#E8E4DD` | 线稿图标（偏暖的纸白） |
| `text_primary` | 白色 94% | 标题、应用名 |
| `text_secondary` | 白色 46% | 副标题、说明 |
| `text_eyebrow` | 白色 32% | 顶栏小字 |
| `focus_stroke` | 白色 92% | 焦点环 |
| `move_stroke` | `#FFB74D` | 移动模式描边（唯一的彩色） |

## 图标

- 24×24 viewport 的矢量图，放在 `res/drawable/`。
- 只用 1.6dp 描边线稿，`strokeLineCap="round"`、`strokeLineJoin="round"`；允许实心小三角这类必要的填充。
- 描边色统一引用 `@color/icon_stroke`，不要在图标里写死颜色。
- 桌面卡片直接使用系统应用自己的 banner 或图标，不自绘应用图标。
- 顶栏按钮等自有控件才需要新建图标，命名 `ic_<用途>.xml`。

## 卡片

- 尺寸按窗口真实像素的比例计算（`ui/shell/ScreenMetrics.kt`），不用固定 dp；电视面板与密度差异很大，写死 dp 会在某些电视上明显偏小。
  - 常用行 宽 22.0% × 高 19.5%
  - 应用行 宽 16.8% × 高 15.0%
- 间距 1.2% 屏高；图标 30% 卡片高；卡片标签 2.6% 屏高。顶栏标题 4.2%、时钟 5.8%、日期 1.9%。
- 相册等其它页面仍用 `tile_w` 240dp × `tile_h` 135dp。
- 表面用 `@drawable/tile_bg`：圆角、暗色底、左上角径向微光、1dp 描边；不要用 `setBackgroundColor` 覆盖。
- 内置应用与信号源：图标居中偏上（48dp，向上 8dp），名称在左下角，12sp，单行省略。
- 第三方应用：有 banner 用 banner 铺满；没有 banner 时用应用图标加名称。

## 焦点

- 焦点环 2dp `focus_stroke`，卡片放大 1.085 倍，动画 120ms。
- 移动模式换成 `move_stroke` 描边，顶栏副标题显示「方向键移动 · OK 完成」。
- 左右在行内移动、上下换行，都不循环；换行时选横向中心最近的卡片。

## 桌面结构

1. **常用**：最多 7 项，默认空；顺序按加入先后，可左右重排。
2. **应用**：始终列出全部可启动应用，不做隐藏。
3. **顶栏控制中心**：右上角齿轮进入，包含信号源提示、图像、声音、网络、安卓设置、开发者选项。桌面不内置相册、播放器、文件管理器等应用。

## 文案

- 只写中文，不再维护英文资源；非中文系统会回落到默认的中文文案。
- 短句，一句说清一个动作。按钮用动词，说明用陈述句。
- 单位（MB、HDMI、AV）保留原写法。
